# 요구사항 정의서

## 기능 요구사항

### 로그 수집
- 시스템 또는 애플리케이션에서 발생하는 로그를 수집한다.
- 로그에는 시간, 메시지, 위험도, 발생 위치 등의 정보를 포함한다.

### 로그 저장
- 수집된 로그를 DB에 저장한다.
- 저장된 로그는 대시보드와 분석 모듈에서 조회 가능해야 한다.

### 보안 이벤트 탐지
- 백엔드 server -> Kafka -> AI sever 의 흐름으로 이벤트를 처리한다.
- 특정 조건에 따라 위험 이벤트를 분류한다.
- AI 분석 결과를 바탕으로 이상 징후를 탐지한다.

### 대시보드
- 전체 로그 목록을 조회할 수 있다.
- 위험 이벤트를 시각적으로 확인할 수 있다.
- 시간별/위험도별 통계를 확인할 수 있다.

## 비기능 요구사항

### 성능
- 로그 발생 후 일정 시간 내에 대시보드에서 확인 가능해야 한다.

### 확장성
- 추후 다양한 로그 소스와 AI 모델을 추가할 수 있어야 한다.

### 유지보수성
- 백엔드, AI 분석, 대시보드를 모듈화하여 관리한다.

### 배포
- Docker 또는 클라우드 환경에서 실행 가능해야 한다.
