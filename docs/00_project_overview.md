# 프로젝트 개요

## 프로젝트명
AI 기반 실시간 보안 아키텍처 설계 및 구현

## 프로젝트 목적
실시간으로 발생하는 로그 데이터를 수집하고, AI 기반 분석을 통해 이상 징후 또는 보안 이벤트를 탐지하여 대시보드에서 확인할 수 있는 시스템을 구현한다.

## 주요 기능
- 로그 수집
- 로그 저장
- 보안 이벤트 탐지
- AI 기반 이상 탐지
- 대시보드 시각화
- 클라우드 기반 배포

## 팀 구성 및 역할
- 오나균(팀장): 프론트엔드 개발 / 백엔드 개발 / 인프라 구축 / 전체 아키텍처 설계 / 최종 발표
- 김진섭: 보안 관련 오픈 데이터셋 탐색 및 정제 / 테스트 시나리오 작성 / 보안 아키텍쳐 설계 / 최종 발표 
- 남현욱: AI 모델 개발 / 데이터 분석 / 중간 발표

## 사용 기술
- Backend: Spring Boot 또는 FastAPI
- Database: MySQL
- Infra: Docker, AWS 또는 클라우드 환경
- AI: Python 기반 모델
- Dashboard: React 또는 기타 시각화 도구
