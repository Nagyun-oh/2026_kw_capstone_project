# P7 — 인증·소량 연결 검증

작성일: **2026/11/05**

[EC2 목차](README.md) · [실행 조건](P1.md) · [시계·자원 감시](P5.md)

P7은 정상 HTTP 3건·시험용 탐지 요청(probe) 1건을 보내 실제 관리자 브라우저까지 연결되는지 확인한다. 복구 후 정상 HTTP 1건을 추가한다. **성능·탐지율 판정이나 1→3→5 RPS 부하 실험이 아니다.** P8 목표 확정 전에는 기존 EC2 전체 부하 실행 제한을 유지한다.

## 수행 순서

1. 새 회차를 예약하고 계획·실행기 해시를 보존한다. 양쪽 호스트 메모리·NTP·서비스 상태를 확인하고 시계 오프셋 구간을 다시 측정한다.
2. 기존 WAF 제외 목록·해당 발생기 IP의 블랙리스트 상태를 Git 제외 복구 파일에 보존한다. 첫 정상 HTTPS 요청의 서버 requestId로 DB의 실제 IP와 SSH 출구 IP를 대조한다. 클라이언트의 전달 헤더로 IP를 대체하지 않는다.
3. 열린 자동화 Chrome에 사용자가 직접 EC2 관리자 계정으로 로그인한다. STOMP 준비 이벤트를 기다린다. 비밀번호·쿠키·세션 파일·스크린샷은 저장하지 않는다.
4. 기존 제외 목록에 발생기 IPv4 하나만 추가하여 WAF 서비스만 재생성한다. `.env.aws`는 편집하지 않고 Compose 호출 시 해당 변수만 전달한다. `nginx -t`·실행 환경·건강 상태를 확인한다.
5. 정상 2건과 기존 시험 fixture 1건을 추가 전송한다. 요청 수는 최초 정상 요청을 포함해 4건이며 probe는 재시도하지 않는다. TLS 검증·대상 호스트 허용 목록·응답 크기·시간 제한을 유지한다. 로그인 응답 토큰은 버린다.
6. requestId별 로그 저장·AI 완료, probe의 WAF/AI 탐지 각 1건, 같은 alertId의 전송·실제 수신·알림 DOM·대표 위협 행을 대조한다. 최신 적용 보고와 발생기의 `CONFIGURED_EXCLUSION`도 확인한다.
7. 시작 시 없었고 원인 위협이 이번 probe에 연결된 등록만 기존 관리자 세션·CSRF 삭제 API로 정리한다. 로그·탐지·알림 기록은 보존한다. 기존 등록이나 출처가 불명확한 등록은 지우지 않는다.
8. WAF 제외 목록을 원래 값으로 복원·재생성한 뒤 건강 상태·적용 보고·정상 HTTPS 접근을 확인한다. 이번 변경 외의 설정이 바뀌었다면 덮어쓰지 않고 복구 미확인으로 보고한다.

차단 제외는 실제 IP에 적용되므로 같은 NAT 출구를 공유하는 기기도 영향을 받을 수 있다. P7에서 일시적으로만 적용하며 일반 보호 정책으로 남기지 않는다.

## 실행

프로젝트 루트 PowerShell:

```powershell
.\build\e2e-venv\Scripts\python.exe -X utf8 scripts/testing/run_ec2_connection.py --dry-run

$ec2Host = '<현재 EC2 주소>'
$ec2Key = '<기존 개인 키 경로>'
.\build\e2e-venv\Scripts\python.exe -X utf8 scripts/testing/run_ec2_connection.py --execute-check --ssh-host $ec2Host --identity-file $ec2Key --round 1
```

기존에 검증된 키 별칭이 필요한 경우 `--host-key-alias <기존 별칭>`을 추가한다. 호스트 키 검증을 해제하지 않는다. 실제 실행은 P1에서 합의한 임시 변경·복구까지 수행하므로 단순 현황 조회 명령과 구분한다.

## 판정과 복구 기록

- 연결 PASS: 정한 4건의 저장·완료·출처·알림·표시, IP 대조·적용 보고, 시험 등록 정리·설정 원복까지 모두 확인한 경우다.
- 미확인·관측 실패·로그인 시간 초과는 INCONCLUSIVE다. 성능 합격 기준은 적용하지 않는다.
- 자원 감시는 P5 기준을 재사용한다. 의도적인 WAF 재생성은 감시와 잠금으로 분리하고, 변경 후 새 기준선으로 다시 시작 조건을 확인한다.
- 원본은 `build/test-runs/<ID>/`, 공유 보고서는 `runs/<ID>.md`다. `private-state.json`에만 발생기 IP·원래 제외 목록을 남긴다. 이 파일은 공유·커밋하지 않는다.
- 비정상 종료로 원복이 미확인되면 이 복구 파일과 실제 WAF 제외 설정·블랙리스트를 먼저 대조한다. 차단 등록을 남긴 채 제외부터 해제하거나 다른 등록을 일괄 삭제하지 않는다.
- 앱 SHA가 바뀌거나 제외 설정을 외부에서 변경한 경우 자동으로 덮어쓰지 않는다. 도구는 코드 배포·DB 스키마 변경·토큰 변경을 하지 않는다.

대표 행 재확인은 기존 기록 조회만 수행했다. 새 JuiceShop 요청·probe·부하·차단 제외·등록 삭제를 하지 않았다. 비밀번호·쿠키·전체 화면·IP·탐지 설명 원문은 결과에 저장하지 않고 API의 ID·출처와 DOM 확인 결과만 남겼다.

재확인 전용 도구는 다음과 같다. `--execute`가 없으면 계획만 출력한다.

```powershell
.\build\e2e-venv\Scripts\python.exe -X utf8 scripts/testing/recheck_ec2_table.py --source-run 20261105T195628+0900-ec2-connection-r03 --execute --round 1
```

P7 준비 단계는 종결했다. 성능 SLO·중단·반복 기준 확정과 전체 EC2 부하 실행기 연결은 P8에서 수행한다. 현재 전체 부하 실행 제한은 유지한다.
