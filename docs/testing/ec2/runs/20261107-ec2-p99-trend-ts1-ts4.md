## 해석할 때 주의할 점

- 36표본 p99는 상위 1~2건 사이의 보간값이라 흔들림이 크다. TS_3 후 WAF 알림 표시 p99가 908.1 → 1,044.0ms로 늘어난 것도 이 범위의 변동으로 본다.
- 기준선 → TS_1 후에 서버 쪽 p99가 늘었다. 요청 → AI 결과 커밋은 1,178.3 → 1,567.6ms다. TS_1은 알림 발행만 바꿨으므로 이 구간과 무관하다. 측정일(11/06 → 11/07) 차이와 회차 변동으로 본다.
- TS_3 단계의 파이프라인 p99 감소는 원인을 확인하지 않았다. 인덱스는 파이프라인 경로의 쿼리를 바꾸지 않는다.
- 기준선과 TS_4 후의 누적 차이(AI 알림 표시 p99 2,149.7 → 1,204.4ms, WAF 1,620.5 → 633.0ms)는 참고값이다. 측정일·브라우저 버전(156 → 157)·DB 규모가 달라 개선률로 계산하지 않는다.
- HTTP p99는 55~74ms에서 움직였다. 개선 대상이 아니다. TS_4 후 최대값 306.7ms는 단일 표본이다.
