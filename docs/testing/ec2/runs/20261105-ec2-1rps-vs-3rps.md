# 2026/11/05 — EC2 개선 전 1 RPS·3 RPS 비교

[EC2 목차](../README.md) · [1 RPS](20261105-ec2-1rps-baseline-review.md) · [3 RPS](20261105-ec2-3rps-baseline-review.md)

각 단계는 120초·3회 모두 PASS했다. 앱 SHA·이미지·실행기·계약·fixture·도구 버전 등 기록된 고정 조건은 입력 RPS를 제외하고 일치했다. DB는 초기화하지 않아 데이터가 늘었다. 아래 값은 원본 표본 합산 분포이며 개선 전 두 부하의 관측값이다.

| 구간 | 1 RPS 표본 | 1 RPS p50 / p95 / p99 ms | 3 RPS 표본 | 3 RPS p50 / p95 / p99 ms |
| --- | --- | --- | --- | --- |
| 정상 HTTP — PC/k6 | 324 | 38.445 / 97.122 / 353.750 | 1044 | 27.976 / 89.337 / 139.294 |
| WAF 접수 → 로그 커밋 | 360 | 309.327 / 529.189 / 568.446 | 1080 | 300.815 / 525.342 / 555.701 |
| 로그 커밋 → AI 결과 커밋 | 360 | 323.468 / 570.611 / 652.522 | 1080 | 357.131 / 605.351 / 703.430 |
| WAF 접수 → AI 결과 커밋 | 360 | 621.789 / 1004.396 / 1149.121 | 1080 | 664.372 / 1016.607 / 1108.587 |
| WAF 접수 → WAF 탐지 커밋 | 36 | 321.278 / 608.147 / 721.366 | 36 | 463.687 / 613.642 / 668.187 |
| 요청 → AI 알림 DOM — PC | 36 | 1313.077 / 2267.622 / 2360.404 | 36 | 1352.479 / 2219.375 / 2243.057 |
| 요청 → WAF 알림 DOM — PC | 36 | 1204.224 / 1381.441 / 1836.131 | 36 | 1037.184 / 1373.071 / 1514.993 |

- AI/WAF 서버 p95는 두 단계 모두 3초 목표를 충족했다. 합산 AI 서버 p95는 약 1.004초→1.017초, WAF는 약 0.608초→0.614초로 관측됐다.
- 이 관측만으로 지연 차이의 원인·통계적 유의성·knee point를 확정하지 않는다. 개선 작업 없이 얻은 값이므로 개선 성과로 표현하지 않는다.
- 정상 HTTP는 PC/k6 관측이며 서버 구간과 구분한다. WAF/브라우저 표본은 각 단계 36건으로 p99는 참고값이다.
- probe 0.1 RPS는 고정하고 정상 요청을 늘렸으므로 탐지 이벤트 전용 처리량 비교가 아니다.
- 부하 중 처리 완료 EPS·lag 추이는 각 회차 progress.jsonl을 사용한다. 순간 lag 최대나 최종 drain 건수만으로 한계 EPS를 정하지 않는다.
- 다음은 개선 전 5 RPS 측정이다. 10 RPS 이상은 앞 단계 결과와 별도 상한·중단 기준을 확인한 뒤 진행한다.

같은 이름의 JSON에 원본 집계 SHA와 분포를 보존했다.
