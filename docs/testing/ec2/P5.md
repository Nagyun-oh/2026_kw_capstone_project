# EC2 P5 시계·자원 감시와 중단 장치

P5는 **측정값을 해석할 시계·자원 근거와, 실험을 멈추는 장치**를 준비한다. 구현·전체 회귀·실제 읽기 전용 관측을 완료했다. 실제 부하·OOM·재시작 장애는 주입하지 않았으며 EC2 부하 실행은 P6~P8 준비 전 차단한다.

후속 [P6 DB 관측](P6.md)도 완료했다. 아래 검증 수치는 P5 완료 시점의 기록이며 현재 다음 단계는 P7 소량 연결이다.

| 항목 | 동작 |

## 시계 계산과 해석

PC 송신 `c0`, 서버 수신 `s1`, 서버 송신 `s2`, PC 수신 `c3`에서 서버−PC 오프셋은 다음 구간으로 남긴다.

```text
하한 = s2 − c3 − 정밀도 여유 1ms
상한 = s1 − c0 + 정밀도 여유 1ms
여러 표본의 교집합 = 관측 가능한 오프셋 구간
```

네트워크가 대칭이라고 가정해 정확한 보정값 하나를 만들지 않는다. 구간 폭은 불확실성이며 정밀도·왕복 지연을 포함한다. PC나 EC2의 시간을 변경하지 않고 SQL에 9시간을 더하지 않는다. 로컬 ±100ms 규칙은 유지하고 EC2 연결 검증에만 별도 보정을 전달한다.

서버 내부 지연은 WAF·백엔드의 서버 시각으로, 브라우저 지연은 PC 단조 시계로 계산한다. PC HTTP 시간에서 네트워크 추정치를 빼서 서버 시간을 만들지 않는다. 보정 유효 기간은 초기 300초이며 각 회차에서 새로 확보해야 한다. 최종 구간 폭 허용치·갱신 주기·HTTP 기준은 P8에서 확정한다.

## 구현한 중단 기준

[P1](P1.md)에서 제안한 자원 기준을 별도 `ec2-observation-v1` 프로필로 구현했다. 성능 SLO·최종 실험 계약과 구분하며 P8 확인 전 임의로 EC2 부하 실행을 열지 않는다.

| 조건 | 동작·판정 |
| --- | --- |
| 시작 전 PC 또는 EC2 여유 메모리 2GiB 미만 | 시작 차단, INCONCLUSIVE |
| 어느 호스트든 여유 메모리 1GiB 미만이 관측상 15초 지속 | 중단, INCONCLUSIVE. 양쪽 타이머를 분리하고 회복·누락 시 지속 시간을 다시 계산 |
| 필수 자원 수집 연속 2회 실패 | 중단, INCONCLUSIVE |
| 자원 표본이 15초 넘게 끊김 | watchdog 중단, INCONCLUSIVE |
| 컨테이너 종료·OOM·unhealthy·재시작·교체 또는 서버 재부팅 | 중단, FAIL. 관측한 상태 이상이며 성능 원인은 별도 분석 |
| 높은 CPU·steal | 우선 기록. 부하 중 높은 CPU만으로 자동 중단하지 않음 |

관측 간격은 초기 5초 대기이며 조회 시간이 추가된다. 메모리 15초 지속 기준은 관측한 표본에 근거한 조건으로, 표본 사이의 모든 순간을 증명하지 않는다. 실제 부하 단계의 감시 제공자·관측 객체 생성과 HTTP·지연·lag 기준 결합은 P6~P8 연결 검증에서 마무리한다. P5 수집 전용 CLI에는 부하 프로세스가 없다.

## 실행과 결과 위치

프로젝트 루트 PowerShell에서 계획만 확인할 수 있다. 파일·SSH·부하는 생성하지 않는다.

```powershell
.\build\e2e-venv\Scripts\python.exe -X utf8 scripts/testing/run_ec2_watch.py --dry-run
```

기존 SSH 정보로 읽기 전용 실제 연결을 확인할 때:

```powershell
$ec2Host = '<현재 EC2 주소>'
$ec2Key = '<기존 개인 키 파일 경로>'
.\build\e2e-venv\Scripts\python.exe -X utf8 scripts/testing/run_ec2_watch.py --check-only --ssh-host $ec2Host --identity-file $ec2Key --samples 5 --round 2
```

새 호스트 키를 임의 승인하거나 검증을 끄지 않는다. 검증된 같은 서버의 기존 별칭이 필요한 경우 P4 안내를 따른다. 원본은 `build/test-runs/<ID>/`의 manifest·clock·sample·summary JSON, 보고서는 EC2 runs에 남는다. 실패·시작 차단도 보존한다.
