# 실험 기록: YYYY/MM/DD — 실험 제목

> [실험 가이드](README.md)에 따라 `docs/testing/<local|ec2>/runs/<실험-ID>.md`로 복사한다. 아래는 미실행 템플릿이다. 예시·목표·추정을 실측값으로 채우지 않는다. 상대 링크는 보고서 위치에 맞춰 조정한다.

p50·p95·p99를 포함한 지연 지표는 요청 건수·측정 기간·반복 회차와 함께 보고한다. 없는 백분위는 미측정으로 남기고 다른 요약값으로 추정하지 않는다. p50은 중앙값을 보여주는 참고 지표이며 별도 합격 상한을 추가하지 않는다. HTTP 응답과 AI 처리 완료 지연은 분리한다.
