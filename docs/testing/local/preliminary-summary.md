## S — Situation: 배경과 시작 상태

- 부하·장애 테스트 전에 실행기와 증거 수집이 실제 로컬 서비스에서 동작하는지 확인할 필요가 있었다.

## 포트폴리오에 사용할 수 있는 현재 근거

> 로컬 WAF 경로에 1회/초로 60초간 요청을 발생시켜 HTTP 요청 61건 모두의 성공과 p95 5.44ms를 관측했다. 실험별 식별값으로 조회한 로그 61건과 연결된 AI 탐지 61건을 대조했고, 종료 직후 AI consumer lag 3이 후속 조회에서 0인 것을 확인했다. 이 결과는 저부하 예비 실험이며, 전체 E2E·탐지 정확도·최대 처리량 검증은 후속 과제로 구분했다.

원본은 `build/` 아래 Git 제외 대상이며 별도 보관 위치·기한은 미확정이다. 정리 전에 삭제하지 않도록 유지하고, 장기 보관할 때는 검증 기록의 SHA-256과 함께 보존한다. 보고서의 상대 링크는 저장소 루트 기준 원본 디렉터리가 함께 있을 때 접근할 수 있다.
